# Generative AI Professional Skills

## Project Overview

This repository contains focused implementations of advanced generative-AI and large-language-model concepts. Each task is designed as a practical exercise that explains or demonstrates an important part of modern AI systems.

## Topics Covered

- Scaled dot-product attention.
- Custom BPE tokenization and causal language modeling.
- Quantization and logit extraction.
- HNSW vector indexing.
- Transformer backpropagation.
- Retrieval-augmented generation and cross-encoders.
- LoRA fine-tuning.
- Multi-agent blackboard architectures.
- Vector-stream ingestion.
- Diffusion models.
- Prompt guardrails.
- Knowledge distillation for vision-language models.
- DPO reward alignment.
- CUDA/SwiGLU kernels.
- Enterprise LLM gateways.

## Purpose

The project is a technical learning portfolio for understanding how generative-AI systems work from mathematical foundations through production-oriented infrastructure and safety patterns.
